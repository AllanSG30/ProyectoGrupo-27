============================================================
1. DESCRIPCIÓN GENERAL
============================================================

FideStore es un proyecto académico que implementa una base de datos
relacional para gestionar clientes, direcciones, categorías, productos,
proveedores, inventario, pedidos y detalle de pedidos.

La lógica principal de base de datos fue desarrollada utilizando Oracle
Database, SQL y PL/SQL. El proyecto también incluye una capa de
aplicación desarrollada en Python utilizando el controlador
python-oracledb.

El repositorio se divide principalmente en:

- Sql/: scripts de creación y programación de la base de datos.
- Python/: archivos para conexión y ejecución de funcionalidades desde Python.
- README.md: documentación general del repositorio.
- LEAME.txt: instrucciones para configurar y ejecutar el proyecto.


============================================================
2. REQUISITOS
============================================================

Para ejecutar completamente el proyecto se requiere:

- Oracle Database o un ambiente Oracle compatible con PL/SQL.
- Python 3.10 o superior.
- pip para instalar dependencias de Python.
- Git, únicamente si se desea clonar el repositorio.
- Una herramienta para ejecutar scripts Oracle, por ejemplo:
  - Oracle SQL Developer.
  - Oracle FreeSQL para ejecutar y validar los scripts SQL/PLSQL.

Dependencia de Python:

oracledb>=2.0

============================================================
6. INSTALACIÓN DE PYTHON
============================================================

Con Python 3.10 o superior instalado, abrir una terminal desde la raíz

Esto instalará el controlador python-oracledb necesario para establecer
la comunicación con Oracle Database.


============================================================
7. CONFIGURACIÓN DE LA CONEXIÓN
============================================================

Antes de ejecutar Python se debe editar el archivo:

Python/conexion.py

Dentro del archivo se encuentra una configuración similar a:

CONFIG = {
    "user": "fidestore_app",
    "password": "CAMBIARCONTRASEÑA",
    "dsn": "localhost:1521/XEPDB1"
}

Estos valores son ejemplos y deben reemplazarse según el ambiente Oracle
en el cual se haya cargado la base de datos.

Se deben configurar:

user:
Usuario del esquema Oracle.

password:
Contraseña correspondiente al usuario.

dsn:
Dirección del servidor Oracle utilizando el formato:

host:puerto/servicio

Ejemplo para una instalación local de Oracle XE:

localhost:1521/XEPDB1

La configuración puede variar según la instalación o ambiente utilizado.


============================================================
8. EJECUCIÓN DE LA APLICACIÓN
============================================================

Después de instalar las dependencias, configurar conexion.py y crear
los objetos de la base de datos, ejecutar desde la raíz del proyecto:

python Python/main.py

El programa mostrará un menú en consola relacionado con el módulo de
pedidos.

Entre las operaciones disponibles se encuentran:

1. Crear un pedido.
2. Agregar un producto a un pedido.
3. Consultar detalle y total de un pedido.
4. Cambiar el estado de un pedido.
5. Consultar pedidos de un cliente y su resumen.


============================================================
9. FUNCIONAMIENTO DE LA CAPA PYTHON
============================================================

La capa Python utiliza procedimientos almacenados definidos previamente
en Oracle.

La lógica principal no utiliza consultas SQL directas para realizar las
operaciones principales del módulo de pedidos.

Python utiliza llamadas a procedimientos almacenados mediante
python-oracledb.

Algunas operaciones dependen además de triggers de Oracle para validar
stock y realizar acciones automáticas sobre el inventario.


============================================================
10. CONSIDERACIONES IMPORTANTES
============================================================

- Los scripts deben ejecutarse respetando el orden indicado.
- La aplicación Python requiere una instancia Oracle accesible desde el
  equipo donde se ejecuta.
- Las credenciales incluidas en conexion.py son valores de ejemplo y
  deben configurarse antes de iniciar la aplicación.
- No se deben utilizar credenciales administrativas para la aplicación.
- Los datos de prueba pueden generar errores de duplicidad si se
  ejecutan más de una vez sobre el mismo esquema.
- Oracle FreeSQL puede utilizarse para validar los scripts SQL y PL/SQL.
  Para ejecutar la aplicación Python se requiere una instancia Oracle
  a la cual Python pueda conectarse mediante un DSN válido.
- Los resultados obtenidos pueden variar dependiendo de los datos
  previamente existentes en la base de datos.
